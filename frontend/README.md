# Healthy Foods Chatbot

เว็บต้นแบบแชตบอทแนะนำอาหารเพื่อสุขภาพ รองรับ flow:

1. เก็บชื่อ อายุ และเพศของผู้ใช้
2. เลือกเป้าหมาย: ลดน้ำหนัก, เพิ่มกล้ามเนื้อ, ควบคุมน้ำหนัก, อาหารเพื่อสุขภาพ
3. ระบุอาหารที่แพ้
4. แนะนำอาหาร 3 เมนูตามเป้าหมาย
5. เปิดดูรูป ชื่อ แคลอรี่ โปรตีน ไขมัน และคาร์โบไฮเดรต

## การใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที ข้อมูลโปรไฟล์ถูกเก็บใน `localStorage` ของเบราว์เซอร์ และกดปุ่มลูกศรหมุนมุมขวาบนเพื่อเริ่มใหม่

## โครงสร้างข้อมูลสำหรับต่อ Postman API

ข้อมูลเมนูอยู่ใน `app.js` ตัวแปร `foods` และแบ่งตาม `goal` ดังนี้:

- `users`: `name`, `age`, `gender`, `goal`
- `goals`: `id`, `label`, `description`
- `food_categories`: หมวดอาหารของเมนู
- `foods`: `name`, `goal`, `calories`, `protein`, `fat`, `carbs`, `image`, `note`

เมื่อต่อ backend สามารถแทนที่ `localStorage` และข้อมูล array ใน `app.js` ด้วย endpoint จาก Postman Mock Server ได้โดยไม่ต้องเปลี่ยนโครงหน้า UI
